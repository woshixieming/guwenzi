# 查一个字，看见它的不同模样

从家谱里的陌生写法，到书页上的生僻汉字，用「汉字书体溯源」查读音、看字形、找繁异体线索。

## 一、读旧书，常常被一个字难住

翻开一页家谱，可能会遇到这样的文字：

> 諱○○，字○甫，行三，生於乾隆丙午年，配王氏，子二：長淸源、次淸浩。

「諱」怎么读？「淸」和「清」有什么关系？另一个看着眼熟的字，如果既不知道读音，又打不出来，该从哪里查起？

阅读家谱、地方志和古籍时，难点往往不只在“认不认识”，还在于怎样找到原字、怎样理解它与通行写法之间的关系。

**「汉字书体溯源」把查读音、看书体、找繁异体和读字义放在一起，让一个陌生字有了更多查找线索。**

## 二、一个字，九个字形展示位

找到目标字后，打开详情，可以对照九个展示位中的不同写法：

| 展示内容 | 可以观察什么 |
| --- | --- |
| 楷体 | 熟悉的现代楷书字形 |
| 繁体 | 以宋体呈现的繁体写法 |
| 毛笔楷 | 毛笔楷书中的笔画与结构 |
| 隶书 | 隶书中的线条与结体 |
| 行书 | 行书中的笔画呼应 |
| 草书 | 草书中的连写与省变 |
| 篆书 | 优先采用峄山碑字体，缺字时由说文小篆补充 |
| 说文小篆 | 字体收录的《说文解字》相关字形 |
| 甲骨文 | 字体中与现代汉字编码对应的甲骨字形 |

从「山」「林」「家」这样的熟悉字开始，也可以从一个姓氏入手：同一个字换一种写法，部件的位置、线条的走向、整体的疏密，都值得细看。

九个展示位，并不意味着每个字都有九种完整字形。各套字体的收字范围不同，缺少的字形会明确标注「未收录」；隶书借用明确的单字繁体对应时，也会标明实际展示的字形。

**书体对照适合观察，不能直接当作一张经过考证的汉字演变图。** 字体编码中的对应关系，也不能替代具体字源与古文字释读的证据。

## 三、不知道读音，也能从字形找起

查字不必只有一条路。根据手边已有的线索，可以选择不同入口。

### 知道怎么读，用拼音查

支持带调或不带调的拼音，例如 `yǒng` 或 `yong`。找到候选字后，可以继续查看字义与书体。

### 认得部首，按部首找

「部首查找」提供现代规范和传统康熙两套归部方式，方便按不同查阅习惯找字。两套列表分别包含 259 项和 213 项，这是当前规范字数据生成的检索列表，并非两套部首体系的完整总数。

### 能数出笔画，按笔画筛选

「笔画检字」按总笔画数列出候选字，还可进一步限定部首。这里主要面向 8,105 个规范字；寻找表外写法，可以转到「异体字查找」。

### 认得部分结构，用部件组合查

在「部件拆字」中输入「士 口」或「士+口」，可以查找「吉」等匹配结果，部件顺序不影响组合检索。输入单个字，还能查看已收录的拆分方式。

部件拆分提供的是找字线索，不应直接视为字源解释。

## 四、字打不出来，先按原字找候选

遇到一个不会读、也无法输入的旧字形，可以打开「异体字查找」，按**原字自身的部首和笔画**缩小范围。

这个入口支持组合筛选：

- 按部首查找，并选择总笔画或部外笔画。
- 笔画数拿不准时，勾选包含相邻笔画 ±1。
- 填入可辨认的部件，进一步减少候选字。
- 找到相似字形后，查看原字、对应规范字候选及关系来源。

例如，原文中的「淸」可以查到「清」的对应线索，「塟」可以查到「葬」。查找结果会列出本地字库记录的依据，便于继续核对。

这里既有繁简、异体对应，也有仅供参考的语义关联。**参考字不等于可以直接替换的字；没有查到对应关系，也不代表原字写错。**

人名、地名和古籍特殊用字尤其需要保留原文。如果出现多个候选，应结合读音、含义和上下文判断。

当前「截图找字」暂未开放。面对照片或扫描件，可以先观察字形，使用部首、笔画和部件查找；已有可编辑文字时，也可以直接粘贴单字查询。

## 五、查到字，再看看字义、书证和笔顺

找到一个字，往往只是阅读的第一步。

单字详情会按收录情况展示读音、部首、笔画、结构、繁异体关系、字义和古籍书证，帮助把字形与具体含义联系起来。

其中，《说文解字》及相关注本材料单独列在「字源」区块，与普通释义分开展示。查阅时，可以将这些材料与书体字形对照阅读；涉及具体字源结论，仍应结合其他可靠研究资料判断。

笔顺动画则让笔画的先后次序更直观，支持重播和慢速播放。陪孩子认字、辨认不熟悉的结构，或练习书写前做一次观察，都可以从这里开始。

并非每个字都有完整资料，字义、字源和笔顺的覆盖范围也各不相同。

## 六、目前收录了多少内容？

按当前项目本地数据核对，主要收录情况如下：

| 内容 | 数量与口径 |
| --- | --- |
| 主字库与扩展字库 | 合计 44,354 个不同汉字 |
| 规范字 | 8,105 字，以《通用规范汉字表》为基础 |
| 表外字 | 36,249 字，补充部分读音、部首和变体信息 |
| 字义 | 覆盖 20,964 字 |
| 《说文》相关材料 | 覆盖 3,947 字 |
| 笔顺动画索引 | 覆盖 9,565 字 |

这些数量分别统计汉字、释义和笔顺等不同资料，覆盖范围存在交集，不能相加作为总字数；收录某个字，也不代表它具备全部书体和全部信息。

对于家谱与地方志阅读，可以从陌生写法追查对应线索；对于书法学习，可以先比较不同书体的结构；对于日常识字，则可以把读音、字义和笔顺放在一起看。

## 七、资料有出处，使用有边界

项目使用了 Unicode Unihan、OpenCC、漢語拆字字典、《汉语拼音辞典》、CC-CEDICT 等数据来源，以及多位字体作者和机构提供的资源。笔顺展示使用 Hanzi Writer 组件及 Hanzi Writer Data 数据。

相关来源、署名和许可已在项目资源说明中整理。不同数据、字体与组件适用各自的使用条款，部分资源的来源、版本及授权凭据仍待补齐，不能统一表述为“全部可自由商用或再分发”。

字义、书证和字形对应关系也需要持续校对。如发现错字、漏字、出处或署名问题，欢迎反馈。

---

一个字，可能有熟悉的读音，也可能有陌生的写法。把它放进不同书体、不同资料中再看一遍，常常会多出一个值得追问的问题。

**从一个姓氏、一处地名，或旧书里偶遇的字开始，查一查，也多看一眼。**
