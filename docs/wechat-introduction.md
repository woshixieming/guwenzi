# 查一个字，也看看它的不同模样：分享一个「汉字书体溯源」小工具

有些字，我们每天都在用，却很少停下来仔细看。

换成隶书，它是什么样子？写成草书，还能认出来吗？家谱里那个似曾相识的字，是繁体、异体，还是自己没有见过的写法？

一次查字，常常会带出更多问题。

于是，我做了一个小工具，叫作「汉字书体溯源」。希望把查读音、看字形、找繁异体、读字义这几件事，放到同一个页面里。

**让查字多一点直观，也多一点继续追问的乐趣。**

## 把同一个字，放在不同书体里看看

输入一个汉字，打开详情，就能对照它在楷体、毛笔楷、隶书、行书、草书等字体中的不同模样，也可以查看繁体写法，以及字体收录的篆书、说文小篆和甲骨文字形。

平时看惯了印刷体，再换一种写法，常常会注意到原先忽略的部件、线条和结构。

你可以从自己的姓氏开始，也可以试试「山」「林」「家」这些熟悉的字。先看自己能认出哪些，再看看不同字体怎样安排它们的笔画。

当然，各套字体的收字范围并不相同。遇到缺少的字形，页面会标注「未收录」，不会保证每个字都有完整的九种展示。

还需要说明：**书体对照不等于一张已经考证完成的汉字演变图。** 字体里的对应关系可以帮助观察，具体字源和古文字释读，仍要结合可靠资料来判断。

## 不知道读音，也可以换个入口查

查字时最常见的困难，往往就是“不知道它读什么”。

工具提供了几种入口：可以直接输入汉字，也可以输入带调或不带调的拼音；还可以按部首、笔画检索，或者尝试用部件组合找字。

部首浏览提供现代归部和传统康熙归部两种方式，方便在不同查阅习惯之间切换。

主字库以《通用规范汉字表》的 8,105 字为基础，并结合 Unicode Unihan 数据补充表外字的部分读音、部首和变体信息。

查到一个字后，还可以继续查看已有的字义、书证、繁异体关系和笔顺动画。各项内容取决于数据收录情况，不同字的资料完整程度会有所不同。

## 读家谱时，先把陌生写法找出来

这个工具里还有一个我比较想推荐的入口：**家谱识别**。

把一段已经整理成文字的家谱内容粘贴进去，工具会逐字比对规范字表和繁异体字库，列出需要留意的字，并提供已有的对应关系及来源提示。

对于能够映射的写法，还会给出一份便于继续阅读的参考文本。

这里的“识别”处理的是文字。老照片、手写页和扫描件，需要先转成可编辑文本，再交给工具比对。

人名、地名和古籍中的特殊用字尤其需要保留原文核对。一份方便阅读的转换结果，可以帮助定位问题，但不宜直接代替原始记载。

## 从一次查询，走向多看一眼

这个项目适合怎样使用？

陪孩子认字时，可以一起看笔顺，比较不同写法；练习书法时，可以拿它做字形观察的入口；阅读家谱、地方志或古籍时，可以先查找陌生字和繁异体线索。

即使没有明确的学习任务，也可以随手输入一个喜欢的字，看看它在不同字体里的模样。

我希望它能让“查到了”之后，多一个“原来还可以这样看”的瞬间。
